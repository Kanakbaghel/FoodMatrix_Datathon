## 📌 About the Project

This repository holds all the work for **Team FoodMatrix's** submission to the Women in Data "What's Cooking?" Datathon 2026. Our project explores global food trade data from **FAOSTAT** to uncover insights around import/export dependency, trade relationships, and food security implications tied to international trade patterns.

We're analyzing how countries depend on each other for food and agricultural trade, and what that means for resilience, risk, and food security — using real, open data and turning it into a clear, actionable story.

## 🚀 Getting Started (For Team Members)

1. **Clone the repo:**
   ```bash
   git clone https://github.com/<org-or-username>/FoodMatrix-Datathon-2026.git
   cd FoodMatrix-Datathon-2026
   ```

2. **Set up a virtual environment (recommended):**
   ```bash
   python -m venv venv
   source venv/bin/activate      # Mac/Linux
   venv\Scripts\activate         # Windows
   ```

3. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Create your own branch before making changes:**
   ```bash
   git checkout -b yourname-feature
   ```

5. **Push your work and open a Pull Request** into `main` — see [CONTRIBUTING.md](CONTRIBUTING.md) for our full workflow.
